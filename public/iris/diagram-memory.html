Memory architecture — confidentiality by construction

Discretion isn't a choice Iris makes in the moment; it's what memory is even reachable when composing a message.

returned to Iris for this message withheld anonymized aggregate

Confidentiality by construction, not by promise. Each private caucus is its own store; a de-identified synthesis layer can read across them but only emits anonymized aggregates. Every item is tagged by provenance, and the access layer scopes each retrieval to the person Iris is talking to — so another person's private silo is simply not reachable. Iris can't "decide" to snitch, because it can't see it.
